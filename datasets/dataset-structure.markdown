# Prepare a dataset

Start with the [README quick start](../README.markdown#quick-start). This guide describes the files the loader expects; it does not download or convert source datasets.

## Paths and required files

GravityNet reads from `<dataset_path>/<dataset>/`. For example, `--dataset_path datasets --dataset INbreast` reads `datasets/INbreast/`.

```text
datasets/INbreast/
├── images/
│   ├── all/
│   │   ├── sample001.tiff
│   │   └── sample002.tiff
│   └── masks/                         # optional
│       └── sample001.mask.png
├── annotations/csv/all/
│   ├── sample001.csv
│   └── sample002.csv
├── split/
│   └── split-1-fold.csv
├── lists/
│   ├── normals.txt                    # used by FP_images: normals (default)
│   └── all.txt                        # used by FP_images: all
└── statistics/
    └── rescale=1.0/
        └── split-1-fold-statistics.csv # generated by the statistics script
```

Folders such as `info` and `script` may be used for your own notes and preparation code; the launcher does not require them.

## Images, annotations, and masks

Use matching names for each image and its annotation CSV. Configure extensions **without a leading dot**, for example `images_extension: tiff` and `annotations_extension: csv`. The annotation folder is always `annotations/csv/all`, even if you change the annotation extension.

An annotation CSV contains one lesion center per row, in original-image pixel coordinates (`X` is horizontal, `Y` is vertical):

```csv
X,Y
120,340
245,512
```

For an image with no lesions, supply a CSV containing just the `X,Y` header. Every image in the split needs its annotation file.

The default `num_channels: 1` expects a two-dimensional grayscale image. The current `num_channels: 3` transform expects channel-first image data (`3 × H × W`); ordinary channel-last RGB files need adaptation. Images in a batch must have compatible dimensions. Prepare dimensions divisible by 32 after rescaling for gravity-point alignment.

Masks are optional. With `images_masks_extension: png`, the loader looks for `images/masks/<name>.mask.png`; if absent, it uses a full-image mask with value 255. `images_masks_extension: none` also uses the full image.

## Split files

Set `split: 1-fold` to select `split/split-1-fold.csv`. A split file needs these columns:

```csv
INDEX,FILENAME,SPLIT
0,sample001,train
1,sample002,validation
2,sample003,test
```

This is a format example; use enough real samples for training and evaluation. Keep `INDEX` equal to the zero-based row position, without gaps, because the loader uses it as a dataset index. `FILENAME` excludes the extension. Use exactly `train`, `validation`, or `test` in `SPLIT`, and provide nonempty subsets for the standard workflow, which initializes all three subsets even in test mode.

The repository provides the following splits:

| Dataset | `split` values | Files |
| --- | --- | --- |
| INbreast | `1-fold`, `2-fold` | [Splits](INbreast/split) |
| E-ophtha-MA | `1-fold`, `2-fold` | [Splits](E-ophtha-MA/split) |
| Cervix93 | `default` | [Split](Cervix93/split) |

## Evaluation lists

The `FP_images` setting chooses which images count toward false-positive evaluation:

| Setting | Required list | Contents |
| --- | --- | --- |
| `normals` (default) | `lists/normals.txt` | Names of images with no lesions |
| `all` | `lists/all.txt` | Names of all images in the dataset split file |

Each list contains one filename per line, without an extension or CSV header:

```text
sample002
sample004
```

Keep the lists consistent with your data and evaluation protocol. Evaluation on normal images needs normal images in the evaluated subsets; if your dataset has none, choose an appropriate protocol such as `FP_images: all` and supply `all.txt`.

## Generate statistics before training

Create the statistics directory for your chosen rescale value, then run the script with the same YAML you will use for training:

```bash
mkdir -p datasets/INbreast/statistics/rescale=1.0
PYTHONPATH=. python script-dataset/Dataset-Statistics.py script_dataset \
  --cfg configs/INbreast.yaml
```

The script writes image counts, normal-image counts, annotation counts, and intensity statistics for each subset. Training and testing read this file even with `norm: none`. Regenerate it after changing data, annotations, split, or rescale. See the [statistics guide](../script-dataset/script-dataset.markdown).

For a custom dataset, copy a preset, update its dataset name and data settings, create this folder structure, and generate statistics before launching `train_test`.
